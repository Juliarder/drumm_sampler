# Drum Machine

Интерактивная браузерная драм-машина на чистом JavaScript.

Проект выполнен как техническое тестовое задание и демонстрирует работу с DOM, событиями клавиатуры, HTML Audio и визуальным состоянием интерфейса без использования фреймворков.

## Live demo

[Open Drum Machine](https://juliarder.github.io/drumm_sampler/)

## Возможности

- 9 звуковых клавиш: `A S D F G H J K L`
- отдельный аудиосэмпл для каждой клавиши
- воспроизведение звука по нажатию клавиатуры
- визуальная реакция активной клавиши
- защита от повторного запуска при удержании клавиши
- остановка предыдущего звука при запуске нового

## Стек

- HTML5
- CSS3
- Vanilla JavaScript
- HTML Audio API

## Как запустить

1. Клонировать репозиторий:

```bash
git clone https://github.com/Juliarder/drumm_sampler.git
```

2. Открыть папку проекта.
3. Запустить `index.html` в браузере.
4. Использовать клавиши `A S D F G H J K L`.

## Исходное техническое задание

Нужно было реализовать драм-машину, в которой:

- клавиши `A–L` запускают соответствующие звуки;
- активная клавиша визуально увеличивается;
- при запуске нового звука предыдущий останавливается.
